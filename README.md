# Metatrader_4_MQ4_SL_Automatic_Order
Script para MT4 que asigna automáticamente un Stop Loss por defecto asignando monto fijo (ej. 30 USD) a las órdenes manuales. No sustituye al trader, solo reduce errores y limita pérdidas por descuido. Si defines un SL mayor, lo ajusta inicialmente y luego puedes modificarlo. Uso bajo tu responsabilidad; revisa siempre el código antes de ejecutarlo
